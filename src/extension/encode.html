JAI encoder

Turns an image into a JAI description by analysis by synthesis: a vision model describes the image, image models render the description, the renders are compared with the original, and the description is revised until the renders match as closely as the run's limits allow.

Runs on Replicate, as chosen under “Render with” in the options.

No renderer is set up yet. Open the options to connect JAI Studio or add a Replicate token.
