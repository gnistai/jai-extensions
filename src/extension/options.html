JAI Viewer

The reference viewer for JAI (Just AI Images). It renders JAI images only when you ask, with the renderer and models you choose here.

How rendering works. When you render a JAI image, this extension sends its description to the renderer you choose below. With JAI Studio, the desktop app, it goes to JAI Studio's server on this computer: nothing leaves the computer and nothing costs money. With Replicate, the description, and for "transform" images the picture shown on the page, goes to Replicate with your own API token. Replicate processes and may log what you send under its terms, and charges your account per image; nothing is rendered there until you allow it for a site. Nothing is sent to any other server.

Render with

Each renderer can be chosen once it is set up below, and connecting JAI Studio chooses it. The extension never switches to the other renderer by itself: not when the chosen one fails, and not when it is removed.

JAI Studio on this computer

Checking…

Copy the token in JAI Studio: Copy next to the token in the Server tab, or Copy server token in the tray menu. JAI Studio must be running on its usual ports (5240 to 5249). With "Keep running in the tray when the window is closed" (on by default) it goes on running after you close its window, and on Windows it can start in the tray when you sign in. Connecting asks for permission to reach this computer's own address (127.0.0.1). The token is stored only in this browser profile, in the extension's private storage; the background worker sends it only to a JAI Studio on this computer that has proved it holds the same token, and web pages and the extension's in-page code never see it.

Replicate API token

Checking…

Create one at replicate.com/account/api-tokens. It is stored only in this browser profile, in the extension's private storage, and is used only by the extension's background worker to call api.replicate.com. Web pages and the extension's in-page code never see it.

Replicate models

A JAI document can name preferred models, but only models enabled here are ever used on Replicate. A document can never make the extension download or run anything else. JAI Studio renders every document with its FLUX.1 schnell.
