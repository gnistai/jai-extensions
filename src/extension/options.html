JAI Viewer

The reference viewer for JAI (Just AI Images). It renders JAI images only when you ask, with the provider and models you choose here.

How rendering works. When you render a JAI image, this extension sends its description, and for "transform" images the picture shown on the page, to Replicate, using your own API token. Replicate processes and may log what you send under its terms, and charges your account per image. Nothing is sent to any other server, and nothing is rendered until you allow it for a site.

Replicate API token

Checking…

Create one at replicate.com/account/api-tokens. It is stored only in this browser profile, in the extension's private storage, and is used only by the extension's background worker to call api.replicate.com. Web pages and the extension's in-page code never see it.

Models

A JAI document can name preferred models, but only models enabled here are ever used. A document can never make the extension download or run anything else.
